# 🎓 GradePilot

⭐ Project Overview

GradePilot is a student-focused web application designed to help users calculate, track, and estimate SGPA/CGPA based on academic goals 📊. The platform supports academic planning by helping students understand the scores required to reach target CGPA goals for placements and overall performance improvement.

It also includes a peer-based notes sharing system 📚 where students can upload and access study materials shared by fellow students and seniors. This makes exam preparation more practical and comfortable, especially for students who prefer learning through peer-shared resources and simplified notes.

📂 Main Features

- SGPA & CGPA Calculation
- Academic Goal Estimation
- Student Login & Signup
- Notes Upload & Access
- Peer Learning Support
- Student-Based Academic Planning

🏗️ Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB

🌟 Purpose of the Project

The project aims to simplify academic planning and improve accessibility to student-friendly learning resources through collaborative learning and performance estimation.
